# ML-EEG-Eyelid-Prediction

*NOTE:* Please see the final .html file for the results, as it is the knitted version of the .rmd file. It has instructions, descriptions and visualizations for clarity. I will provide a really short overview of the project here.

The goal of this project was to train multiple ML Classification algorithms, like Decision Trees, Random Forest, AdaBoost, XGBoost, Support Vector Machines, KNN. Hyperparameter tuning was also implemented to automatically find the optimal hyperparameters for the appropriate prediction models.
The goal was to predict wether a patient has their eyelids open or closed, based on 16 types of EEG features.

The following prediction models used were:

- Decision Trees
- Support Vector Machines
- KNN - K-nearest neighbor
- Random Forest, AdaBoost, and XGBoost.
Finally, I made a comparison of all the models and made a verdict on which model has the best prediction capabilities based on measurements like Precision, Recall, Accuracy and F1-score.
